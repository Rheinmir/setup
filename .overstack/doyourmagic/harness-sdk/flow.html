Cùng chữ "harness", khác tầng

Đọc cái này trước, nếu không phần so sánh sẽ thành so táo với cam.

Với Strands, harness là một agent lắp sẵn: create_harness() trả về một strands.Agent thường đã gắn đủ 11 tool (shell, đọc/ghi/sửa file, web, subagent, todo…), memory, session, bộ nhả context (offload — cắt kết quả tool dài ra đĩa, để lại bản xem trước) với giá trị mặc định họ nói là đã đo benchmark.

Với overstack, harness là lớp quản trị bao quanh một agent có sẵn (Claude Code): 22 luật cắn bằng hook, cổng kiểm, wiki, và một dàn công cụ đo. Vì thế chỉ so được hai trục user hỏi: cách đánh giá và cách tổ chức.

Sơ đồ luồng — skill nào sinh ra gì, nuôi skill nào

Bẫy đã đo

Mỗi mục là một lần chạy thật, không phải đoán.

Fixture MCP gọi python, máy chỉ có python3

test_subagent_delegate_inherits_parent_mcp_tools FAIL với No such file or directory: 'python'. Đặt bin của venv lên đầu PATH thì xanh.

Thiếu PATH venv và biến AWS thì bộ unit chạy 24 phút, đỏ

Lượt đầu: 7 failed, 8 errors (đều test MCP), mất 24 phút. Đặt venv bin lên đầu PATH và thêm AWS_EC2_METADATA_DISABLED=true AWS_REGION=us-east-1 thì xong trong 50 giây, xanh. Chưa tách được biến nào gây chậm.

Model không có web search thì tool bị bỏ lặng lẽ

Bedrock Opus 5 (mặc định): harness chỉ in cảnh báo, web_search biến khỏi danh sách tool, không lỗi.

Số benchmark không tái lập được

Trang benchmark trích file .xlsx không có trong repo; harness chạy benchmark nằm ở repo khác.
