Thuật ngữ

deps (phụ thuộc)
Node phải XONG trước thì node này mới được chạy. Dây đứt = tool suy ra từ Consumes/Produces, chưa ai khai tường minh.
lớp topo (topological layer)
Nhóm node không phụ thuộc nhau → chạy song song được. Lớp sau chỉ mở khi lớp trước xong.
lease (thuê khoá)
Khoá có hạn giờ. Hết hạn mà chưa báo xong → node về unknown (không rõ), không tự kết luận hỏng.
generation (thế hệ giao việc)
Mỗi lần giao lại tăng 1. Kết quả mang gen cũ bị bỏ, tránh agent chết-sống-lại ghi đè lần giao mới.
verify
Lệnh shell trả 0 = task xong thật. Không có verify thì tối đa chỉ đạt done_unverified (xong nhưng chưa ai kiểm).
stale (cũ)
Node đã xong nhưng node nó phụ thuộc bị làm lại → kết quả có thể lệch; chỉ cảnh báo, không tự lùi trạng thái.
HITL / AFK
HITL = cần người sống quyết định, không giao cho agent headless. AFK = agent tự chạy được.
